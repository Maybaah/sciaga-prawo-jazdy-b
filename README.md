# Ściąga kat. B

Skrót zasad ruchu drogowego dla prawa jazdy kategorii B, napisany prostym językiem, ze słowniczkiem terminów (światła, płyny, podzespoły, manewry) i rosyjskimi odpowiednikami.

Materiał zbudowany **wyłącznie** na oficjalnej bazie pytań egzaminacyjnych Ministerstwa Infrastruktury — `KATALOG dla kandydatów na kierowców, 07/2026`. Nie ma tu niczego spoza tego pliku.

Zakres: 3698 pytań w katalogu, z czego 2299 dotyczy kategorii B (razem z arkuszem „W trakcie weryfikacji”). 2046 z nich ma film albo zdjęcie i sprawdza konkretną sytuację na drodze — te trzeba przeklikać w symulatorze. Ściąga powstała z pozostałych 477 pytań tekstowych i specjalistycznych, w których reguła jest zapisana słowami.
